번호 HTTP 요청 본문 (설정) 응답 본문 (수신) 소요 시간 결과

선택한 크기의 정적 파일을 GET으로 받습니다. 128KiB도 정상 응답 대상이며, POST 요청 본문의 64KiB 제한과는 별개입니다.

POST는 선택한 크기의 데이터를 /echo로 보냅니다. 64KiB 이하는 같은 크기의 응답, 128KiB·512KiB·1MiB·100MiB는 413 차단이 예상됩니다. POST 응답 크기는 요청 크기에 따라 정해지므로 별도로 선택하지 않습니다.

요청 본문 (설정)은 브라우저에 전달한 본문 크기입니다. HTTP 헤더는 포함하지 않으며, 서버가 전부 받았다는 의미는 아닙니다. 64KiB 초과는 즉시 413으로 거절하며, 응답 송신 후 남은 데이터를 최대 2초 동안 읽어 버리고 연결을 닫습니다.

100MiB는 요청 하나당 104,857,600바이트입니다. 남은 업로드를 2초 안에 정리하지 못하면 연결 / 수신 실패나 시간 초과로 표시될 수 있습니다.

요청마다 다른 쿼리와 캐시 비활성화 옵션을 사용합니다. 브라우저가 연결을 나눠 보내거나 대기시킬 수 있으므로, 요청 수가 서버의 실제 동시 연결 수나 작업자 동시 실행 수를 의미하지는 않습니다.

개발자 도구의 Network에서 GET은 concurrency=, POST는 echo로 필터링해 요청 시간대를 확인하고, 서버 터미널의 accept·close 로그도 함께 살펴보세요. 요청별 시간에는 브라우저 대기와 본문 수신 시간이 포함됩니다.
