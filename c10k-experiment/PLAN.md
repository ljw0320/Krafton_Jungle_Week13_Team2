# 로컬 C10K 연결 유지 실험

승인된 구성: 저장소 밖 복사본 세 개, 공통 Python 측정기, 동일 정적 파일 및 조건.

1. HTTP 응답 경계와 오류 집계 테스트를 먼저 검증한다.
2. git archive로 고정 커밋을 복사하고 실험용 조건 변경 및 diff를 남긴다.
3. 동일 O2 빌드, 12000 연결 상한, 600초 유휴 시간으로 설정한다.
4. 0/100/500/1000/3000/10000 대기 연결에서 정상 요청과 자원을 측정한다.
5. 프로세스형은 WSL 전체 보호를 위해 서버 프로세스 1100개 제한을 두고, 그 이상 단계는 미실행으로 기록한다. 모델의 한계로 해석하지 않는다.
6. 3회 반복, 측정 8초, 정상 요청 초당 10회. 원본 로그/CSV/환경/요약을 저장한다.

메모리 PSS와 프로세스 CPU는 측정 구간 전후에 수집한다. 클라이언트도 동일 WSL에서 실행되므로 독립된 부하 발생기 결과와 동일하게 해석하지 않는다.
